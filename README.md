# Teens Connect Africa

Production-ready React + Vite + TypeScript + Tailwind platform scaffold for a non-profit with public website, volunteer portal, founder CMS, Firebase Authentication, Firestore, Storage rules and Netlify deployment.

## Setup
1. Copy `.env.example` to `.env` and add Firebase web app credentials.
2. Run `npm install`.
3. Run `npm run dev`.
4. Deploy to Netlify with build command `npm run build` and publish directory `dist`.

## Firebase Collections
`users`, `roles`, `programs`, `events`, `announcements`, `reports`, `gallery`, `partners`, `documents`, `settings`, `newsletter`, `contactMessages`, `volunteerApplications`, `attendance`, `tasks`.

## Media Placeholders
Upload folders are scaffolded for logo, hero images, team photos, program images, gallery images, partner logos, sponsor logos, documents, reports and videos.
